# Web: семейная галерея в браузере

Laravel 13 + Inertia 3 + React 19 + Tailwind 4 + shadcn/ui — тот же стек, что у
MyTube (`mytube/api`). Оформление — от веб-клиента MyTube (тёмная тема как у
Apple TV, «стеклянные» шапка и панель вкладок), приёмы галереи — от Immich:
лента ровными рядами по дням, полоса времени справа, «В этот день»,
просмотрщик на весь экран со сведениями о кадре.

**Сейчас это прототип на тестовых данных.** Все страницы читают библиотеку
через интерфейс `App\Gallery\GalleryCatalog`; привязан `FakeGalleryCatalog` —
сгенерированная библиотека (~4,5 тыс. кадров, 2019 — сегодня), картинки с
picsum.photos, видео — один CC0-ролик. Настоящий источник займёт его место
одним классом, страницы и API не изменятся.

## Запуск

```bash
composer install && npm install
cp .env.example .env && php artisan key:generate
npm run build            # или npm run dev — с горячей перезагрузкой
php artisan serve --port=8010
```

http://localhost:8010. Базы данных не нужно: сессии и кеш — в файлах.

## Что есть

| Страница | Что |
|---|---|
| `/` Фото | лента по месяцам и дням; месяцы догружаются из `GET /api/timeline/{YYYY-MM}` по мере прокрутки; полоса лет справа; «В этот день» |
| `/albums` | альбомы из метаданных, как у индексатора: места, камеры, годы + «Избранное» и «Видео» |
| `/albums/{id}` | альбом с шапкой из обложки и слайд-шоу |
| `/photos/{id}?from=…` | просмотрщик: ← → / свайп, Esc, `i` — сведения, `f` — избранное, пробел — слайд-шоу. `from` задаёт, что листается: `album:<id>`, `day:<дата>`, `search:<запрос>`, без него — лента |
| `/search?q=` | по городу, стране, камере, году, месяцу: «Казань июль», «видео 2024» |

Выбор нескольких кадров: кружок при наведении (на телефоне — долгое нажатие) или
кружок у заголовка дня; шапка превращается в панель действий. Избранное в
прототипе хранится в сессии; «Скачать» пока только показывает уведомление.

## Дальше — настоящий API

`GalleryCatalog` повторяет каталог индексатора (`workers/indexer.py`, схема v4):
`photos` — кадры, `albums`/`photo_albums` — альбомы мест, камер и лет, `meta` и
`manifest.json` — ревизия. Настоящая реализация:

1. читает опубликованный каталог (`.gallery/manifest.json` → `catalogs/index-<rev>.db`)
   с шары Photos, смонтированной в контейнер только на чтение;
2. отдаёт миниатюры, превью и видеопрокси из `.gallery/thumbs/` с долгим кешем
   (адрес содержит хеш содержимого — кеш можно не сбрасывать);
3. хранит избранное у себя (в каталоге индексатора его нет).
